# Templates (frozen copy for older app versions)

GibTalk 1.0.20 and earlier read the templates in this folder, straight from
GitHub. Newer versions get them from the symbols API
(`https://api.gibtalk.com/api/templates`), and the templates are now edited in
the [api-gibtalk](https://github.com/ragibkl/api-gibtalk) repo (`templates/`).

Keep this folder so older installs keep working. Changes made here only reach
those older versions.
